# Amazon-sales-india-dashboard

# Project Overview

This project analyzes Amazon India sales data using Microsoft Excel and presents the results through an interactive dashboard.

# Objectives

- Analyze total orders and sales.
- Identify category-wise sales.
- Analyze state-wise orders.
- Understand order status distribution.
- Calculate return rate.
- Identify the revenue loss

# Tools Used

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Excel Formulas
- Dashboard Visualization

# Project Files

1. Amazon Sales Data India.xlsx – Original dataset.
2. Pivot Tables Excel Files – Data analysis using Pivot Tables.
3. Pivot Tables PDF Files – Pivot Table reports.
4. dashboard.xlsx – Excel dashboard workbook.
5. dashboard.pdf – Final dashboard report.
6. project review.pdf – Project documentation and explanation.

# Key Analysis

- Overall Sales and Profit Performance
- Category-wise Sales and Profits
- Category-wise Units Sold
- Top 10 Products by Sales
- State-wise Orders
- Order Status Distribution
- Return Rate Analysis

# Conclusion

This project helps understand sales performance, order trends, product categories, and return patterns through data analysis and visualization.
